trz-popup

Enhanced Features & Accessibility!

Configuration: You can now customize default CSS class names and control automatic button injection. Place your configuration script before trz-popup.js: 


<script>
  // Example: Configure before trz-popup.js loads
  window.trzPopup = window.trzPopup || {};
  window.trzPopup.configure({
    // toggled: 'my-custom-toggled-class', // Example: override a class name
    // autoInjectCloseButton: false,      // Example: disable auto close button
  });
</script>
<script src="assets/scripts/trz-popup.js?v=1"></script>

Accessibility: This version includes significant accessibility improvements:

  • Keyboard Navigation: Use 'Escape' key to close popups. Focus is managed and trapped within open popups.
  • ARIA Attributes: Popups now use ARIA attributes (role="dialog", aria-modal, aria-labelledby, aria-hidden) to improve screen reader compatibility.

Note: The actual configuration example above is not actively changing this demo page's behavior but shows how you would implement it in your project.
